Staged Import Engine

Two upstream feeds in incompatible shapes become records in a downstream system with two localised views. Sixty-odd modules in seven lanes, twelve gated stages, four independent duplicate detectors, two bracketing gates that read the live target rather than any log, and a memory layer that turns every mistake into a test.

Sources, systems, field names and identifiers are stripped; what is left is the shape. The interesting part is not the transformation, it is how many distinct ways the run can refuse, in what order, and that every refusal is a function with a test rather than a sentence someone has to remember.

The rules that hold it together

  • read back, alwaysA write that reports success is not a write. Every record is read back from the live target, on both views, before it counts.
  • prose is not a gateA correctness rule that exists only in a document is one that will be skipped. It belongs in code where it cannot be.
  • exclude and reportOne incomplete record drops out and names itself. It never blocks the other hundred and fifty that were ready.
  • a hold is a decisionThe push log is append-only and cannot know what was deliberately held, so enabling takes the hold list explicitly.
  • closed is read-onlyA finished run is never written to again. A referee test fails the moment any script tries.
  • fresh is not correctEvery cached snapshot has a shelf life. Preflight checks their age before a batch, and then reads the live target anyway.
  • one joinerA single normaliser for the shared identifier, used by every consumer. Two normalisations of one key is how a record gets counted twice.
  • ratios are alarmsThree silent gates were caught by a number that was too clean, never by an error. Any counter that can reach the whole batch gets an assertion, not a log line.
  • a set, not a keyA unit carries several identifiers. Every check that assumed one eventually met a record with two and called it two products.
  • same function, both pathsRepair and completion call the push's own functions. Two copies of one builder is how only one of them gets the fix.
  • a rejection is a findingWhen the registry refuses a code, it is reporting a duplicate, not an error. Filing it as an error hid four twins.
  • regenerate from the ledgerA generated document that also carries state must source that state, never rebuild it blind. A blind rebuild once wiped the launch record.
  • the file that decides gets a writerThe list deciding what ships had no script producing it and was three weeks stale. Nothing that decides is hand-made now.
  • make a new check fail firstA gate that always fires is as dead as one that never fires, and harder to spot: it teaches the operator to skip the runner.
  • name the unit of every countRows, keys, records and units are different grains. A number without its grain has been wrong here twice.
  • canary, then batchOne record, both views, on the live target, before any batch. The one time this was skipped, the live client was wired to stage.
